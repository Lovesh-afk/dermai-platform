# DermAI chatbot knowledge base

The chatbot (Phase 9) answers ONLY from these notes (retrieval-augmented
generation). Each file is one topic; each `## ` heading becomes one
searchable chunk, so keep every section self-contained.

Rules for this content:
- General educational information only: no diagnosis, no medication doses.
- Every condition note says when to see a doctor.
- Written from widely accepted general dermatology guidance. Before any
  real clinical use, a licensed dermatologist must review every file.
